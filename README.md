# Backend Bootcamp — Manejo de Datos

Material de las 5 clases de "Manejo de Datos" (Semana 2 del bootcamp de backend): introducción a bases de datos, modelado, SQL, relaciones, e interacción desde Node.js con y sin ORM.

## Estructura del repo

Cada clase es autocontenida: tiene su propio README (contenido para alumnos), guía docente (facilitación y tiempos), presentación, y — cuando corresponde — su carpeta de setup, ejercicios y recursos.

```
clases/
  clase-1/
    README.md            — contenido para alumnos
    guia-docente.md       — guía de facilitación (tiempos, notas)
    presentacion.pptx
    setup/                — instalación de herramientas nuevas en esta clase
    ejercicios/biblioteca — dominio guiado (introducido acá, reutilizado en Clase 2)
    recursos/              — referencias de indagación
  clase-2/
    README.md, guia-docente.md, presentacion.pptx
    recursos/
  clase-3/
    README.md, guia-docente.md, presentacion.pptx
    setup/
    starter-api/           — API Express base, garantiza un punto de partida
    recursos/
  clase-4/
    README.md, guia-docente.md, presentacion.pptx
    setup/
    recursos/
  clase-5/
    README.md, guia-docente.md, presentacion.pptx
    setup/
    recursos/
```
