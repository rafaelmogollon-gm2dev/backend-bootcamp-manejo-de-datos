# Banco de Referencias

Material de indagación organizado por tema. Se usa en la dinámica de cada clase: exposición corta → pregunta abierta con estos recursos → puesta en común.

## Fundamentos de bases de datos y modelado

- [Documentación oficial de PostgreSQL](https://www.postgresql.org/docs/) — referencia canónica
- [postgresqltutorial.com](https://www.postgresqltutorial.com) — más digerible que la doc oficial para consulta rápida
- [Database Design Course (freeCodeCamp)](https://www.youtube.com/watch?v=ztHopE5Wnpc) — modelado, normalización y ER (fraccionable en tramos cortos)
- Buscar "1NF 2NF 3NF explicado" en español (canales como HolaMundo o Fazt) para normalización

## SQL y relaciones

- [SQLBolt](https://sqlbolt.com) — ejercicios interactivos gratis, ideales para practicar JOINs en el navegador sin instalar nada
- [Mode SQL Tutorial](https://mode.com/sql-tutorial) — orientado a JOINs y casos reales
- Documentación oficial de las cláusulas SQL en [postgresql.org/docs](https://www.postgresql.org/docs/)

## Node.js + PostgreSQL (driver `pg`)

- [Documentación oficial de node-postgres](https://node-postgres.com) — corta y clara, buena para indagación directa
- Sección de node-postgres sobre pooling de conexiones

## Sequelize

- [Documentación oficial de Sequelize](https://sequelize.org) — secciones "Getting Started" y "Model Basics"

## Prisma (mención comparativa)

- [Documentación oficial de Prisma](https://www.prisma.io/docs) — sección "Quickstart"
- [Prisma tutorial interactivo in-browser](https://www.prisma.io/docs/getting-started) — se puede probar sin instalar nada

## NoSQL (mención)

- [Documentación oficial de MongoDB](https://www.mongodb.com/docs/) — sección de conceptos básicos
- Buscar "MongoDB vs SQL databases" para comparaciones cortas en video

## Buenas prácticas / seguridad en queries

- [OWASP: SQL Injection](https://owasp.org/www-community/attacks/SQL_Injection) — corto y visual
- Documentación de `pg` sobre queries parametrizadas

## Modelado ER / diagramas

- [dbdiagram.io](https://dbdiagram.io) — modelado ER con sintaxis simple, exporta a SQL
- [draw.io](https://draw.io) — alternativa manual, sin exportación a SQL
